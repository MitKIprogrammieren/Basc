Browser
Dieser Browser kann nicht auf USB zugreifen. Öffne die Datei in Chrome oder Edge (Safari und Firefox können das nicht).
1 · Heim-WLAN
Leer lassen, wenn die Waage schon im WLAN war – sie behält es beim Flashen. Nur 2,4 GHz – der ESP32 sieht kein 5-GHz-WLAN. Die Daten gehen nur per USB an die Waage, nirgendwo sonst hin.
2 · Home Assistant und Sensorplatine
Leere Felder lassen, was das Display schon kennt. Token: Home Assistant → Profil → Sicherheit → Langlebige Zugriffstokens. Die Daten gehen nur per USB an das Display.
2 · Waage per USB anstecken
USB-C-Datenkabel an den ESP32-S3-Zero. Klappt das Verbinden nicht: BOOT gedrückt halten, einstecken, loslassen, nochmal versuchen.
Ablauf
  • ESP32-S3 erkennen
  • Firmware und Oberfläche schreiben
  • Neustart und wieder verbinden
  • WLAN übertragen
  • Waage im Netz: –
